Hooh Smart Fill & Sign — from understanding a document to acting on it

After Hooh shipped the reading experience, the next gap was action. People understood their documents but still retyped the same data — name, ID, address, tax number — into every new form. Smart Fill closes that gap: Hooh recognizes form fields and fills them with data already stored in the user's documents, then lets them sign and save without leaving the app.

Problem

Even when a document is clear, action still costs time. People retype the same personal data into every new form, search for where to sign, then convert the result to share or store — and each step that pushed them out to another app was a place the workflow, and the reason to keep using Hooh, quietly leaked. Reading was solved by the first release; everything after it was still manual

Task

Extend Hooh from a reading tool into a complete document workflow. Let users fill and sign any form on iOS using data already available in their previously uploaded documents — without losing control over what gets submitted

Users

The same audience as the first Hooh release — expats, digital nomads, and people without a legal background. Most of them process a handful of new forms every month: visa applications, lease agreements, school paperwork, banking contracts

Scope

Smart Fill mode with manual fallback, a signature flow that supports both drawing and camera capture, an explicit save and version model, and a set of supporting actions for managing pages and formats inside a document

Design process

Sessions with the first-release cohort surfaced a clear pattern: the data a form needed was almost always already sitting in a document the user had uploaded. Smart Fill grew out of that — instead of asking the user to retype, recognize the fields and reuse what Hooh already knows.

The constraint shaping every decision below was trust. Auto-fill is only useful if the user can see what was filled, override it, and turn it off entirely. The whole flow was designed around that veto.

1. Smart Fill — automation with a veto

Hooh recognizes form fields and fills them from the user's stored documents — and nothing is submitted silently. When Smart Fill has a match, the documents it drew from stay pinned at the top, so the user sees its sources; any value can be overridden in place; and a single toggle hands the whole form back to manual entry. It defaults to on because the time saved is the point, but the user is never more than one tap from doing it by hand. When a field has no match, the form highlights it and keeps moving — an unfinished form is a first-class state, not an error.

2. Signature — captured once, reused everywhere

One signature, made once. Draw it on the canvas or capture an existing one with the camera — either way it becomes a reusable asset, saved to a library and ready to drop into the next document. The user makes the signature itself only once.

3. Saving — without fear of overwriting

Saving never overwrites by accident. The original file stays untouched — the user can save a new copy or branch off a brand-new document, and every version lives inside the document itself: switchable from the nav bar and renamable in place. Iterating on the same form keeps every state without cluttering the document list.

Beyond the core flow

Supporting document actions, designed in scope and in the same visual language, reachable from the same document screen.

Reorder pages

Drag pages into the right order without leaving the document

Rotate

Quick page rotation for scans that came in sideways

Add a page

Insert a new page from the camera or from another file in Hooh

Convert format

Convert to Word, Excel, and more from the document screen

Outcome

The flow was designed end-to-end and handed off to engineering. Every decision pulled in one direction: the app removes the repetitive work while the user keeps the final word.

This scope didn't reach a public release as part of this engagement, but the design system, components and flows are documented and ready to ship when the product picks the work back up.
